## The defining shift

**June is the month the GUI became the main event.** One third of all feature
commits are `feat(desktop)`. The Electron app went from 323 files to 801 and
acquired, in four weeks, most of what people now think of as Hermes Desktop:

first-class projects with a coding rail and review pane, a multi-terminal panel
with read-only agent terminals, a memory graph that plays your memories and skills
back over time, PR-style file diffs in chat, concurrent multi-profile sessions with
cross-profile `@session` links, VS Code Marketplace theme installation, a Cmd+K
palette, live subagent watch windows, a pop-out composer, an in-app spot editor,
per-profile themes, and a desktop pet you can scale with Alt+wheel.

**The second shift is commercial.** June is when money appears in the codebase:
`/credits`, `/billing` with an interactive TUI and CLI client, usage-aware credit
notices, and a `/usage` view. Hermes acquired a paid tier and the plumbing to
support it.

**The third is architectural and easy to miss.** `feat(relay)` shows up for the
first time — 17 commits — alongside 16 `photon` commits. This is the beginning of
the connector/relay layer that lets a gateway reach chat platforms through an
external connector rather than holding every credential itself. July finishes it.

## What shipped

### Desktop — 160 feature commits

**Projects and coding.** First-class projects (sidebar, coding rail, review pane,
agent project tools), a resizable VS Code-themed terminal pane, a multi-terminal
panel with read-only agent terminals, terminal tabs and scrollback persisted across
relaunch, an in-app spot editor for the file preview pane, PR-style file diffs in
chat, and worktree-aware sidebar grouping.

**Sessions and windows.** Concurrent multi-profile sessions with cross-profile
`@session` links, a Mac-style session switcher (`^Tab` / `^⇧Tab` / `^1-9`), opening
any chat in its own window, a compact-window hotkey, remembered window
size/position/maximized state, hover-reveal collapsed sidebars, and a conversation
timeline rail for long threads.

**Composer.** Arrow-key history and queue editing, a composer status stack with
live subagent windows and editable prompts, a pop-out draggable floating composer,
drop files anywhere in the chat area, sticky human messages clamped to two lines
until hover, and RTL/bidi auto-detection.

**Appearance.** Install any VS Code theme from the Marketplace, assignable themes
per profile, a unified overlay design system with BrandMark and an onboarding
redesign, a window translucency slider, rebindable keyboard shortcuts, and inline
rich embeds, diagrams, and alerts in assistant markdown.

**Setup and providers.** Dedicated Providers settings, polished Accounts/API-keys
UX, xAI Grok as a first-class OAuth launcher provider, a "choose provider later"
onboarding skip, full tool-backend configuration in Settings, GUI-driven post-setup
tool installs, per-profile remote gateway hosts, and username/password login for
remote gateways.

**Other.** Cron jobs first-class in the sidebar with a dashboard scheduler, native
OS notifications with per-type toggles, a memory graph as a playable timeline,
`/journey` opening that graph, background needs-input indicators, a curated
turn-completion cue, Shift+click the status-bar zap for global YOLO, and the pet
(roam modes, Alt+wheel scaling).

## Reading this month in today's code

- **Desktop's own `AGENTS.md`.** June's volume is why the desktop app has scoped
  architecture rules of its own — the general guide could not keep up.
- **In-place compaction as default.** The two-part flip (`#38763`, then `[2/2]`) is
  the house pattern: ship the option, prove it, then change the default in a
  separate commit.
- **`verify_on_stop` off → auto.** A feature turned off by default, migrated, then
  given a surface-aware default — three commits to get one default right.
- **Relay Phase numbering.** June starts a phased rollout that runs through July's
  Phase 1–4 parity work. When you see `Phase N` in a commit subject, this is the
  project it belongs to.
