## The defining shift

Three things happened at once, and all three point the same direction: **Hermes
became something other people build on.**

**SDKs, not just features.** July shipped a **cross-surface theme SDK** — one skin
themes the CLI, TUI, and desktop, live — plus a **widget-app SDK** for the TUI
(apps as state + reducer + render, with three reference apps) on a new widget-grid
layout engine, plus the **desktop plugin SDK** whose founding plugin is Kanban.
These are not user features; they are contracts for third parties.

**Voice became a real modality.** Fifteen `voice` commits: streaming conversational
TTS with barge-in across all surfaces, telling the model when the user interrupts
its spoken reply, on-device wake words with open-vocabulary phrases and
multi-profile voice routing, and a generic streaming dispatcher for CLI/TUI
`speak_text`. Plus a gateway-side streaming TTS adapter contract.

**The relay hit parity.** June built the transport; July made it equivalent to a
native platform adapter across four numbered phases — `supported_ops` discovery and
wire identity, media egress and inbound localization, native interactive prompts
(approvals/confirms/clarify) with a react-ack lifecycle, and thread lifecycle with
handoff threads, semantic renames, and a hello command manifest.

## Reading this month in today's code

- **`hermes serve` vs `hermes dashboard`.** July's split is why `backendSupportsServe()`
  exists in `apps/desktop/electron/main.ts` — a new app against an un-upgraded runtime has to
  fall back to `dashboard --no-open` or it crashes on an unknown subcommand.
- **Removing the `toolsets` arg from `delegate_task`.** A rare *subtraction* from the
  model-facing schema, and a good example of narrow-waist thinking applied to an
  existing tool.
- **Phase-numbered relay work.** Four phases in one month, each independently
  shippable. Worth copying for any large feature here.
- **The `conformance` vector generator.** Treating renderers as an executable spec
  is the project's answer to change-detector tests for output formatting.
