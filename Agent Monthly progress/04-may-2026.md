## The defining shift

May has two stories running in parallel.

**In the foreground: security and durability.** After three months of adding
surface at maximum speed, May is where the project paid down risk. Secret
redaction flipped **on** by default. Promptware defense arrived — shared threat
patterns, a memory load-time scan, and tool-result delimiters. A supply-chain
advisory checker landed, then on-demand OSV.dev auditing. Bitwarden Secrets
Manager integration. Checkpoints were rewritten from scratch with real pruning and
disk guardrails. `hermes update` gained post-pull syntax validation with automatic
rollback.

**In the background: `apps/desktop/` appears.** 323 files by month end, almost
none of it in the feature log yet. The month's 42 Kanban feature commits and 15
dashboard-auth commits got the attention; the desktop app was being built quietly
and would consume the next three months.

The third quiet story: **Windows became a real target.** `dep_ensure` + `install.ps1`
+ detection completed the Windows bootstrap, and a Docker Desktop–compatible
compose file landed.

## What shipped

### Security — the month's headline

- **Promptware defense** — shared threat patterns, memory load-time scanning, and
  tool-result delimiters
- **Secret redaction enabled by default** (reversing April's default-off decision)
- **Supply-chain advisory checker** + a lazy-install framework and tiered install
  fallback
- **On-demand supply-chain audit via OSV.dev**
- **Bitwarden Secrets Manager** integration with lazy `bws` install, credential
  source labelling, and EU Cloud / self-hosted server URL support
- Confirm prompts for destructive slash commands

### Durability

- **Checkpoints v2** — a single-store rewrite with real pruning and disk
  guardrails
- **`hermes update` syntax-validates critical files post-pull and auto-rolls-back
  on failure**
- `messages.active` flag + rewind primitives in the state store — the foundation
  under `/undo`, `/branch`, and the TUI's `/rewind`
- `hermes prompt-size` diagnostic
- Install-method stamping + Docker detection in config

### Kanban — 42 feature commits, the largest single push

The board went from "exists" to "usable work queue":

- **Multi-project boards** — one install, many kanbans
- **Generic diagnostics engine for task distress signals**, plus a
  `stranded_in_ready` diagnostic for unclaimed tasks
- **Orchestrator-driven auto-decomposition on triage** and `specify` — an
  auxiliary LLM fleshing out triage tasks
- **`goal_mode` cards run workers in a `/goal` loop**
- **Hallucination gate + recovery UX** for worker-created-card claims
- File attachments on tasks; images in task bodies attached to worker vision
- `default_assignee` fallback + per-profile concurrency cap; per-task
  `max_retries`
- Board-level default workdir; warnings that scratch workspaces are deleted on
  completion
- Auto-subscribe gateway chat on tool-driven `kanban_create`
- Dashboard: workspace kind/path inputs, per-platform home-channel notification
  toggles, tooltips and docs links

### Code intelligence

- **LSP semantic diagnostics from real language servers in `write_file`/`patch`**
- **Post-write delta lint** on `write_file` and `patch`, with in-process
  JSON/YAML/TOML/Python linters
- `patch`: indentation preservation, CRLF preservation, per-file failure escalation
- Per-turn file-mutation verifier footer

### Sessions and search

- **`session_search` rebuilt as a single-shape tool** with discovery, scroll, and

- `HERMES_SESSION_ID` exposed to tools via ContextVar + env
- Session recap appended to `/status`
- `X-Hermes-Session-Key` header on the API server for long-term memory scoping

## Reading this month in today's code

- **`feat(docker)!`** — one of just two `!` marks in 3,046 feature commits. When you wonder
  how averse this project is to breaking changes, that is the number.
- **The `MemoryProvider` closure came later, but the reasoning starts here.** May's
  pace of provider integrations is what made "no new in-tree memory providers"
  necessary by the following month.
- **`session_search` as one tool with modes.** May's rebuild is the template the
  rubric now cites against adding multiple narrow tools.
- **Secret redaction default flip-flop** (off in April, on in May) is a good
  example of a default being tuned by real usage rather than decided up front.
