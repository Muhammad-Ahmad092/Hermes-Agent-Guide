## The defining shift

**Plugins stopped being a convention and became a governed platform.** Eighteen
`plugins` feature commits in seventeen days, and they are not incremental:

- **Manifest v2** — schema version, `api_version`, inter-plugin dependencies, a
  pip-dependency declaration seam, and a config schema
- **Capability declarations + an install/update consent flow** — a plugin now
  states what it wants and the user approves it
- **Capability-gated `ctx.call_mcp`** and a capability-gated
  **`ctx.platform_actions`** facade
- **Plugin packs** — declarative, shareable sets of plugins
- **A community plugin index + `hermes plugins search`**
- A `pre_command` observer hook

That is a package manager with a permission model. Combined with the June policy
closing the tree to third-party-product plugins, the direction is unambiguous:
**capability leaves the repo and lives in installable, consented, discoverable
plugins.**

**The second shift supports the first.** A new WebSocket RPC surface landed
specifically so plugin-authored UIs can do what built-in pages do:
`profiles.list` / `create` / `describe` / `configure`, server-side `ui_meta` on
those responses, a profile asset store for avatars, `image.generate` as an RPC,
per-profile MCP server lifecycle RPCs (`mcp.servers.*`), an optional profile param
on `cron.manage`, and an exported `McpTab` + `ToolsetConfigPanel` from the desktop
SDK so a plugin can reuse real Hermes UI instead of rebuilding it.

**The third shift is about scale limits being wrong.** Delegation defaults were
raised sharply after evidence: `max_concurrent_children` 3 → 10 and the subagent
iteration cap 50 → 250, both with migrations. A unified deadline layer landed as
Phase 1 of a bounded-execution primitive.

### The second breaking change in project history

```
feat(runtime)!: require Node 26 across all installers, heal, and upgrade paths
```

Only two `feat!` commits exist in 3,046 features. The first was May's
`feat(docker)!: replace tini with s6-overlay as PID 1`; this is the second. Note
what makes it acceptable: it covers **all** installers plus the `heal` and
`upgrade` paths in one change, so no user is left on a runtime the app can no
longer start. A breaking change here has to bring its own migration for every
install method.

## The pattern in August's fixes

August's most interesting work is in the 1,919 fix commits, not the features. The
`HEAD` commit at the time of reading is a good example:

```
fix(compression): stop an aborted rotation from growing the parent it could not publish
```

And the one before it:

```
fix: prevent handoff leg data loss + surface state.db corruption to users
```

These are not shallow bugs. They are failure-mode bugs in subsystems that have been
running long enough to hit their edges — an aborted compaction rotation leaving the
parent session larger than it started, a handoff losing a leg, a corrupted state
database failing silently. At a 1:5.1 fix-to-feature ratio, this is what most of the
engineering effort is now.

## Where it appears to be heading

Reading only what is in the tree, three directions are visible:

**Extension over inclusion.** The May and June policies closed the tree to new
in-tree memory providers and third-party-product plugins. August built the
machinery — consent, capabilities, packs, a searchable index, and an SDK exporting
real UI components — that makes living outside the tree viable. Expect the core to
stop growing while the ecosystem does.

**Bounded execution as a theme.** The unified deadline layer is explicitly "Phase
1". Delegation caps were raised with migrations. Metrics are "bounded". Compaction
gained an eval harness rather than another heuristic. The project is putting
measurable limits around things that used to be open-ended — note what is still
*not* bounded: there is no local monetary spend cap anywhere in the tree, only the
read-only Nous Portal `spend_cap_usd` field.

**Multi-agent as a first-class shape.** Agent-to-agent messages now render as
attributed cards. Kanban workers take per-task models. Subagent concurrency went to
10 and iterations to 250, with truncation surfaced to the parent. Delegation
transcripts are tailable. The agent talking to other agents is being treated as a
normal case, not an edge case.
